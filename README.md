# 🚀 Modern Landing Page

A fully responsive, modern corporate landing page built with HTML5, CSS3, and ES6+ JavaScript. Designed with a clean UI/UX, smooth interactions, and a mobile-first approach.

🌐 **Live Demo:** [View Live Site](https://poria410-png.github.io/modern-landing/)

---

## ✨ Key Features

- **Responsive Mobile Navigation:** Fully functional hamburger menu with smooth toggle animation and a dark background overlay (`backdrop-filter` effects).
- **Modern CSS Layouts:** Built using CSS Grid, Flexbox, and modern design principles.
- **Interactive JavaScript:** Event-driven navigation controls, smooth scroll behaviors, and optimized DOM manipulation.
- **Performance Optimized:** Clean semantic HTML structure and lightweight CSS/JS assets.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup and accessibility structure
- **CSS3** – Custom properties (variables), Flexbox, CSS Grid, and responsive media queries
- **JavaScript (ES6+)** – DOM manipulation and interactive event handling
- **Hosting & Deployment** – GitHub Pages
